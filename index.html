Value stream mapping · Pareto · Root cause analysis

Redesigning request and work-order workflows

Requests, work orders, and quotations passed through many hand-offs. It was hard to see where time was lost to waiting, rework, or missing information.

Role
CSD Operations Team Leader
Context
Customer service, HVAC manufacturer, 2024–2026
Methods
VSM · Pareto · RCA · standard work
  1. 1

    Map

    Mapped the current-state value stream step by step, separating working time from waiting time.

  2. 2

    Prioritize

    Used Pareto analysis to find the few reasons behind most returned quotations.

  3. 3

    Find causes

    Applied root cause analysis to critical issues and escalations, looking for process causes rather than blame.

  4. 4

    Redesign & track

    Redesigned the workflows and made them visible through Power BI reporting.

Technical sample

Acoustic path analysis per AHRI 885

Each noise path is worked through by octave band: unit sound power, duct and elbow attenuation, end reflection, and room correction, giving the expected level in the space.

The gap to the room criterion sets the insertion loss needed, so each sound attenuator is sized to its path rather than chosen generically.
